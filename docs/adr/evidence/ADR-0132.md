# ADR-0132 Evidence（目标能力 / 对既有 ADR 的影响 / A–H 阶段与测试明细，历史）

> 本文件保存 ADR-0132 的完整 lifecycle、对既有 ADR 的影响、A–H 实施阶段表与详细验收清单；不作为开放实现待办。

## 完整 lifecycle

```text
discover → inspect → install → verify → trust → configure → connect
→ authorize → use → update → revoke → uninstall → cleanup
```

## 实施阶段（A–H，由 ADR-0133–0140 分别冻结）

| Phase | 交付 | 实现 ADR |
| --- | --- | --- |
| A | tools/list pagination、list_changed、runtime disconnect/retry、诊断 | ADR-0133 |
| B | result normalizer、artifact spill、trace/audit correlation | ADR-0134 |
| C | OAuth、secure token lifecycle、Settings authorization | ADR-0135 |
| D | bulk import/export、legacy migration、McpSync wire | ADR-0136 |
| E | workspace/user/env/CLI source resolver、precedence、auto-connect | ADR-0137 |
| F | structured filesystem workspace-root capability | ADR-0138 |
| G | plugin manifest MCP lifecycle、template policy、provenance | ADR-0139 |
| H | marketplace discover/install/update/revoke/uninstall | ADR-0140 |

每一个 phase 需要独立实现 ADR 或对本 ADR 的 implementation addendum，明确 schema、IPC、权限、威胁模型、回滚和验收；禁止以单一“大 PR”混合所有 phase。

## 测试与门禁明细

每个阶段至少有：

- source precedence、workspace walk、migration、sync conflict tests；
- signature/provenance/revocation/install/uninstall cleanup tests；
- OAuth PKCE/state/refresh/revoke/secret non-echo tests；
- pagination、tool list change、disconnect/retry/cancel/budget tests；
- workspace-root containment/symlink/scope-switch tests；
- result normalizer/artifact/redaction tests；
- Settings → host → session → registry → approval → ToolOutcome integration tests；
- invariant tests，证明 settlement、ledger、`expectedRevision` 与 `toolsReplayed:false` 未被 MCP 扩权。

## 体验政策修订

体验层限制由 ADR-0141 放宽（auto-connect、marketplace、install→connect、远程目录、McpSync 客户端、annotations 辅助审批）；Settings 产品面收窄为 list/editor/import/OAuth（ADR-0142），marketplace Settings UI 当前不交付（设计 non-claim，非永久禁止，开放路径见 ADR-0142 §6）。
