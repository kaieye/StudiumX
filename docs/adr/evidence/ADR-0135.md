# ADR-0135 Evidence（state 投影 / 验收清单 / 安全不变量，历史）

> 本文件保存 ADR-0135（Phase C）的 secret-free state 投影、验收清单与安全不变量明细；不作为开放实现待办。

## Secret-free public states

`authorization_required` / `authorizing` / `authorized` / `authorization_failed`。public projection 永不包含 authorization URL、code、state、PKCE verifier、access token、refresh token、endpoint headers 或路径。

## 验收清单（至少覆盖）

1. PKCE entropy/challenge；
2. pending TTL / one-time state；
3. strict callback routing（仅 `studiumx://mcp-oauth/callback`，精确匹配 pending state、未过期、一次性）；
4. encrypted token storage / no plaintext persistence；
5. secret-free public states；
6. unsupported stdio refusal；
7. explicit user action（无自动授权）；
8. revoke / session drop；
9. refresh failure cleanup；
10. IPC schema rejection；
11. Settings projection；
12. 对 effect/settlement isolation 的静态 guard。

真实 provider credentials 不进入 PR CI。

## 关键通道

- 窄 IPC：`teach:mcp-authorize-server`、`teach:mcp-revoke-authorization`。
- OAuth metadata discovery、external browser open、token exchange/refresh 仅由 main process 在明确 authorize/refresh 生命周期中执行。
- stdio 永不进入 OAuth flow；password/client-secret grant 不支持。
