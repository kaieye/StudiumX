# StudiumX 0.1.2

0.1.2 修复了工具调用被历史总开关意外禁用的问题，并将工具能力调整为应用级默认可用，避免模型在需要读取工作区或调用工具时仅思考一轮便结束。

## 更新内容

- **工具调用默认可用**：应用不再以 `tools.enabled` 作为运行时全局禁用门槛；旧配置中该字段即使为 `false`，加载时也会兼容并归一化为允许工具调用。
- **设置页简化**：移除了“启用工具调用”总开关。工具能力由应用默认提供，不再要求用户先找到并开启该选项。
- **保留细粒度安全控制**：工作区信任、工作区读写和 Shell 能力、网络工具、审批模式、沙箱模式、effect policy、路径围栏与运行预算仍独立生效；默认允许工具调用不等于绕过安全边界。
- **改进受限工作区反馈**：当模型请求读取工作区、但当前工作区尚未获得信任时，应用会给出明确的最终说明，而非承诺读取后在单轮对话中止。
- **项目整理**：此版本同时纳入当前工作区已完成的文档、ADR、项目结构与历史资源整理更新。

## 升级说明

已有用户无需手动修改旧设置：历史 `tools.enabled: false` 会被兼容处理为允许工具调用。若要使用工作区相关工具，仍需对对应工作区完成信任授权，并按照需要配置具体能力和审批策略。

## 下载

请选择与设备匹配的 Windows x64、Linux x64 或 macOS Apple Silicon（arm64）安装包。macOS arm64 安装包当前未签名和公证，首次打开时可能出现 Gatekeeper 提示。
