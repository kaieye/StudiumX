# StudiumX 0.1.1

0.1.1 聚焦在线自习室体验：登录后即可进入在线房间，并由服务端统一管理房间分配。

## 更新内容

- **应用级在线自习室 Presence**：认证用户进入桌面端或 Web 应用后即加入在线自习室；即使暂未打开自习室页面，也会显示在房间成员列表中。
- **服务端房间分配**：优先加入仍有空位的活跃房间；当没有可加入的活跃房间时，服务端会生成并分配新的五位房间号，客户端不再创建本地兜底房间。
- **更可靠的房间切换**：随机换房仅采用服务端确认的结果；服务不可用时保留当前房间，避免切换到未在服务端创建的本地房间。
- **README 在线入口**：项目主页新增“在线自习室体验”链接，可直接访问 Web 端。

## 升级说明

在线自习室的服务端需要同步部署与本版本配套的 `StudiumX-Server` 更新，才能使用服务端新房间分配逻辑。

## 下载

请选择与设备匹配的 Windows x64、Linux x64 或 macOS Apple Silicon（arm64）安装包。macOS arm64 安装包当前未签名和公证，首次打开时可能出现 Gatekeeper 提示。
