# StudiumX 0.1.0

StudiumX 是本地优先的 AI 教学工作区：把学习目标、课程、资源和学习记录沉淀在自己的工作区中，让长期学习不再只是零散的聊天记录。

## 这是什么

- **个性化教学**：AI 结合学习目标、已有进度、练习表现和可信资源，组织可执行的下一步计划、课程讲义、复习线索与学习记录。
- **更可靠的教学链路**：工作区文件与 LearningSession ledger 是教学事实来源；教学过程、证据和结果结算可追溯，避免索引或同步状态反向决定教学内容。
- **MCP 与 Skill 调用**：可配置模型提供商与 MCP 连接（含导入和 OAuth），并支持在教学过程中显式调用 Skill；所有工具仍受读写 effect 分类、工作区边界与审批策略约束。
- **一体化学习工作流**：学习计划、课程与资源管理、专注任务、学习空间和分析汇聚在同一个桌面应用中。
