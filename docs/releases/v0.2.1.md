# StudiumX 0.2.1

0.2.1 聚焦于思维导图工作区的原生编辑与 AI 协作体验，并完善了模型适配、设置界面和桌面端交互的稳定性。

## 紧急安装包修复

- **思维导图节点面板**：移除“节点样式”、字体来源及当前布局等重复说明，让右侧样式面板更紧凑。
- **Windows 设置窗口**：打开设置页时，顶部原生拖拽区域会随页面遮罩统一变暗，避免出现割裂的浅色标题栏。

## 更新内容

- **原生思维导图工作区**：思维导图现支持更完整的主题编辑、富文本与图片附件、主题样式和字体、颜色方案、画布与绘图控制、缩略导航、节点操作及首页图库等能力。
- **AI 辅助导图更可靠**：AI 生成过程保留可查看的流式预览，可将建议逐步应用到导图；当模型未提供可展示的推理内容时，界面会明确说明，而不会把运行状态误标为模型推理。
- **更可携带的导图文件**：改进 Markdown、OPML 与可携带导图的导入导出链路，尽量保留关联媒体和导图内容，方便在工作区之间移动与分享。
- **模型原生工具调用**：兼容模型服务的适配层进一步支持原生工具调用、流式响应和工具结果配对；既有的 effect 分类、审批、工作区信任与 ToolOutcome 结算边界保持不变。
- **设置与界面体验**：设置下拉菜单会在视口层显示，避免被卡片裁切；从沉浸式页面打开设置时，侧栏会保持原有可见状态，减少界面跳动；宠物伙伴改为默认关闭、由用户主动启用。

## 升级说明

已有学习工作区和模型配置可继续使用。工具审批、路径围栏、工作区信任以及恢复后不自动重放工具等安全规则不因本次升级而放宽。

## 下载

请选择与设备匹配的 Windows x64、Linux x64 或 macOS Apple Silicon（arm64）安装包。macOS arm64 安装包当前未签名和公证，首次打开时可能出现 Gatekeeper 提示。
